# Arduino Projects

This repository contains **Arduino-based projects**.

---

## Projects Overview

| # | Project | Description | Notes |
|---|---------|-------------|-------|
| ● | Climate Watch - Arduino | Designed a smart environmental monitoring system using an Arduino, DHT11 sensor, DS3231 RTC module, LCD display, and IR remote control. The system displays real-time temperature and humidity data and allows user interaction via remote control. | See [folder](ClimateWatchArduino) for full code and hardware setup |
| ● | Temperature & Humidity Logger | Developed a data logging system using an Arduino-compatible microcontroller and DHT11 sensor to measure temperature and humidity, store readings, and visualize them using Python scripts. | See [folder](TemperatureHumidityLogger) for code and visualization scripts |
